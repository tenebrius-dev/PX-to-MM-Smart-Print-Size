# UI3 Plugin Design System

Этот документ описывает базовые принципы, переменные и компоненты, которые используются для создания плагинов Figma в стиле UI3. Все данные, отступы и комментарии были получены напрямую из официального файла **Figma's UI Kit (UI3)** через Figma API.

## Базовые токены (Tokens)

Дизайн-система строго опирается на CSS-переменные (токены), выгруженные из Figma. Это гарантирует поддержку светлой и темной тем без дополнительного кода.

- **Отступы (Spacing)**: 
  - `var(--ui3-space-1)` = 4px
  - `var(--ui3-space-2)` = 8px
- **Скругления (Radii)**:
  - `var(--ui3-radius-small)` = 2px (используется для чекбоксов)
  - `var(--ui3-radius-medium)` = 5px (используется для кнопок, инпутов, дропдаунов)
  - `var(--ui3-radius-full)` = 9999px (используется для свитчеров и круглых элементов)

## Спецификация компонентов

### 1. Button (Кнопка)
Кнопки используются для основных и второстепенных действий.
- **Размеры**: 
  - Внутренние отступы (padding): `var(--ui3-space-1)` сверху/снизу, `var(--ui3-space-2)` по бокам.
  - Расстояние между иконкой и текстом (gap): `var(--ui3-space-1)`.
  - Скругление углов: `var(--ui3-radius-medium)`.
- **Особые виды (из описания Figma)**:
  - **Button icon split (Сплит-кнопка)**: Комбинация основного действия (слева) и дополнительного меню/шеврона (справа), предоставляющая быстрый доступ к обеим функциям.

### 2. Input (Поле ввода)
- **Размеры**:
  - Высота фиксирована под сетку UI3 (обычно 32px).
  - Скругление углов: `var(--ui3-radius-medium)`.
- **Поведение**:
  - При фокусе используется рамка цвета `var(--ui3-bg-brand)` и соответствующий `box-shadow`.
  - Поддерживает иконки слева и справа.

### 3. Checkbox (Флажок)
- **Размеры**: 
  - Квадрат `16x16` пикселей.
  - Скругление: `var(--ui3-radius-small)` (2px).
- **Поведение**: При выборе (checked) фон меняется на `var(--ui3-bg-brand)`, а иконка галочки становится цвета `var(--ui3-text-on-brand)`.

### 4. Switch (Переключатель / Тумблер)
- **Размеры**: 
  - Трек: `32x16` пикселей со скруглением `var(--ui3-radius-full)`.
  - Ползунок (thumb): `12x12` пикселей, смещается на `16px` при включении.

## Дополнительные правила из макетов (Redlines / Guidelines)

Дизайнеры Figma оставили следующие строгие комментарии для других компонентов, которые следует учитывать при дальнейшем расширении библиотеки:

- **Slider**: Строго запрещено уменьшать ширину компонента менее чем до 100px (*"Do not resize this component to less than 100px width"*).
- **Tooltip**: Тултипы должны уведомлять пользователя о дополнительной информации, связанной с определенным элементом UI (например, инструментом в тулбаре или кнопкой, содержащей только иконку).
- **Comments/Pin**: 
  - Синий цвет означает состояние "unread" (не прочитано).
  - Отображается до 3 уникальных аватаров, если есть цепочка комментариев.
  - Разрешенные (resolved) или неактивные пины отображаются в приглушенном (dimmed) состоянии.

## Архитектура файлов React
Все компоненты лежат в `/src/components/`. 
Они используют традиционные BEM-подобные классы (`.ui3-button`, `.ui3-input`) и сопровождаются локальными CSS файлами. Перед их использованием в `App.tsx` обязательно должны быть импортированы корневые переменные (`ui3-runtime.css`, `ui3.colors.css`, `ui3.sizing.css`).
